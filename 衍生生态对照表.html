方法与局限

  1. 「最后同步时间」无法直接测。上游不发布时间戳，因此本表用条目数当版本指纹：上游 README 徽章的条目总数，减去各项目页面上自己声明的条目数 = 滞后量。这是间接推断，不是官方声明。
  2. 只有「可达性」「条目数」「IP / CDN」是实测，门槛一列照抄上游 衍生项目.md 的原文口径（标「未标注」= 原文也没标注），非本人核验。
  3. 「无法判定」的 4 项不代表内容旧，只代表它没有提供任何可核验的版本信号 —— 这正是本表想暴露的问题。
  4. 可达性是单机单时点结论（出口为福建电信，未开梯子）。Cloudflare 在国内「时通时不通」，3 轮全通只说明此刻通畅，不代表 24 小时稳定。
  5. 条目数采集自页面首屏 HTML 的正则匹配；若某站把条数渲染在 JS 之后，会落进「无法判定」。
